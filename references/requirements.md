Verification status: UNVERIFIED research pointers. Read
year-selection.md first. These 2019, 2025, and 2026 notes are never automatic
defaults. A number, declaration, or packaging instruction is not a **binding

## Unverified 2026 research pointer

### Physical-paper package

| Area | Requirement |
| --- | --- |
| Paper | White A4 paper; single- or double-sided printing is allowed. |
| Margins | At least 2.5 cm on all four sides. Bind from the left. |
| Page 1 | Consent letter. Preserve its official content and format. |
| Page 2 | Numbering page for division/national review. Preserve its official content and format. |
| Page 3 | Abstract-only page: title, abstract, and keywords; target no more than one page. No English translation is required. |
| Page numbers | Begin on the abstract page at Arabic numeral 1; continue consecutively; center in the footer. |
| Main text | Begins on page 4. Do not add a table of contents. The 2026 baseline says no more than 30 pages for the body. |
| Appendix | Unlimited length and must be printed and bound with the body for the physical submission. |

### Electronic submission

- Submit the competition paper and supporting materials as two electronic files, following the registration/entry notice.
- The paper must match the physical paper in content and format, including the appendix, but must exclude the consent letter and numbering page. Its first page is therefore the abstract page.
- The paper is one uncompressed PDF or Word file, preferably PDF, no larger than 20 MB.
- Supporting materials are one ZIP or RAR archive no larger than 20 MB. They should contain all necessary programs, self-consulted data (not the raw data supplied by the problem), and substantial intermediate charts/tables.
- Put a supporting-material file list in the paper appendix. If none exists, state: “本论文没有支撑材料”.
- The consent letter and numbering page must not be placed in the supporting archive.

### Content, anonymity, and reproducibility

- Do not reveal contestant identity, school, or division anywhere in the abstract page, main text, appendix, electronic paper, or supporting archive. Remove identifying metadata and filenames when practical.
- The appendix must list all supporting materials and include every complete, runnable source program used, including Excel/SPSS interaction commands where applicable. If no program was used, state: “本论文没有用到程序”.
- Results in the paper must agree with runnable code and supporting files. Missing, non-runnable, or inconsistent code can disqualify the paper.
- Cite every external or public source, including online sources, at the point of use and in a standard scientific reference list. Never invent references or claim unsupported results.
- Font family, font size, line spacing, and color are not globally prescribed by this baseline. Apply a supplied template or division-specific rule when one exists.

### 2026 AI-use rule when supplied with the entry package

- Put exactly one applicable AI-use statement before the reference list.
- If AI was used, state the bounded purposes and include an anonymous PDF named `AI工具使用详情.pdf` in supporting materials.
- The detail file records tool/model, dates, task stages, representative prompting approach, adoption/modification, and human verification. It must agree with the paper statement and must not contain team or school identity.
- Do not claim that AI was unused when AI participated in analysis, code, visualization, drafting, editing, or verification.

## Conditional verification checklist

Before producing the final paper, first discard every item not supported by the
selected year's inspected authority. Every bullet below is conditional; for
retained items, verify:

- [ ] Year, group, problem choice, and division-specific rules are known or marked as placeholders.
- [ ] If required, abstract and keywords fit one dedicated page and electronic paper begins there.
- [ ] If required, A4 page, four margins >= 2.5 cm, left binding, and no table of contents.
- [ ] Arabic footer page numbers start at 1 on the abstract page and continue consecutively.
- [ ] Body is within the selected year's limit; appendix is included and printable for the physical package.
- [ ] Consent and numbering pages are excluded from electronic paper and supporting archive.
- [ ] No contestant/school/division identifiers occur in anonymous sections, metadata, filenames, code comments, or archives.
- [ ] All cited sources have in-text markers and reference-list entries.
- [ ] The selected year's verified AI-use statement and any required detail file agree.
- [ ] Appendix contains the supporting-material list and runnable source code, or the exact no-program declaration.
- [ ] Supporting archive is one anonymous ZIP/RAR <=20 MB; electronic paper is one uncompressed PDF/Word <=20 MB.
- [ ] Paper results, code, data, and supporting files are mutually consistent.
- [ ] Rendered PDF/Word page order and page count were inspected before delivery.

## Common failure modes

- Putting the consent letter or numbering page into the electronic PDF.
- Starting page numbering at the cover or counting the abstract as page 3 in the electronic file.
- Adding a table of contents or letting the abstract spill onto a second page.
- Omitting runnable code, Excel/SPSS commands, a supporting-material list, or the no-program/no-supporting-material declaration.
- Leaving team names, school names, division names, author metadata, or identifying filenames in anonymous files.
- Treating the 2019/2025 20-page guidance as the 2026 30-page rule, or applying a past year's AI-use rule without checking the current notice.
