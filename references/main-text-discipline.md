# Main-text discipline

Load this reference only for results or full-paper drafting, compression, result
placement, or repeated tables. Its purpose is to make the shortest sufficient
evidence chain visible for every subproblem, without hiding material evidence.

## Classify before placing

Classify each proposed result as one of the following, then choose its smallest
useful destination.

| Class | Default destination | Keep when |
| --- | --- | --- |
| core answer | main text, with a compact caption where needed | it directly answers a required subproblem or changes the decision |
| necessary support | main text or caption | it makes the core answer interpretable or credible |
| qualification | main text near the affected claim | it limits applicability, exposes a trade-off, or changes the conclusion |
| robustness | main text summary with detail in appendix | it establishes that a material result survives reasonable variation |
| intermediate table | appendix or support material, with a distilled value in the main text/caption | readers need the calculation trail but not every row to follow the argument |
| implementation detail | appendix or support material | it is needed for reproduction but not for immediate interpretation |

The defaults are not a license to conceal evidence: keep contradictory or
conclusion-changing evidence in the main text near the claim it qualifies. Do
not omit a required subproblem, and do not remove information needed for
reproduction or interpretation.

## Build and compress the chain

For each subproblem, state only the chain needed to establish: input or
assumption, method, result, interpretation, and any material limitation. Put
the result beside the method it supports; use a figure for a trend or comparison
and a table for exact values. Keep no more than the normally useful two
consecutive tables before interpretation, rather than forming a 2-by-2 or
four-table wall.

Before adding prose, a display, or a row, ask whether it can replace, compress,
or delete something already present. Prefer one result that changes the answer
over several intermediate displays that repeat it. A caption may carry local
definitions, units, sample size, and the immediate takeaway; appendices and
support material preserve necessary detail without breaking the argument.

## Compact audit

For each subproblem, record only: the core answer, its necessary support, any
qualification or robustness evidence, and the location of reproducibility
detail. Flag a missing link, repeated display, contradictory result, or
unjustified deletion. Keep this audit compact by default.
