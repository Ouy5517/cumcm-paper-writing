# Submission preflight

Record the selected year, inspected official notice, and supplied template.
Treat exact requirements as binding CUMCM rules only when supported by inspected
selected-year official sources. Templates implement typography; they are not
independent rule authority. Keep non-binding editorial guidance separate. Record PASS / FAIL /
UNCHECKED / NOT APPLICABLE for coverage, model validity, provenance, authoritative-source agreement, format,
figures, code appendix policy, visual rendering, package and identity requirements.
Count summary/body/references/appendix/disclosure pages only as the verified
selected-year rule specifies.
Verify actual reproduction commands, dependency paths and allowed support files.
Consult problem-coverage.md, model-validation.md, artifact-consistency.md and
code-appendix.md. No required unchecked item can be called passed.
For practical questions, use the selected-year verification questions in
cumcm-practical-faq.md; do not convert its non-binding guidance into a rule.
Use year-selection.md to check the separate format, AI, submission-notice and
regional-rule statuses. For formal competition work report the team's actual
human review status and truthful AI-use record separately from automated checks.
