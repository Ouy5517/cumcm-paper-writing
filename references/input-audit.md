# 输入审计：按材料结构选择检查

只检查本题实际使用的材料。保留原件和可复现变换，不以文件扩展名推断
数据含义。处理前先核对题面口径，处理后抽查关键单元格与计数。

| 材料 | 必须先明确 | 有意义的检查 |
|---|---|---|
| 题面常数、成本表 | 参数、情形、单位、适用问号、页码 | 逐项对照代码；修改上游参数后确认所有下游使用同一版本 |
| 样本表、成分数据 | 实体与采样点层级、检测限/空白/零的含义 | 主键与连接基数；总量约束；排除记录；分组是否混淆对象与测点状态 |
| 时间序列 | 频率、时区、时间顺序、预测时可获得的信息 | 缺期与重复；训练期内拟合变换；滚动或时间外验证 |
| 几何、图片、坐标 | 比例尺、原点、轴方向、角度单位、坐标变换 | 已知点/对称时刻；遮挡与边界；坐标和对象参数使用同一筛选掩码 |
| 网络、路径、事件 | 节点/边/事件含义、方向、权重、状态转移 | 连通性、不可达点、重复事件、守恒及极端输入 |
| 文本或文档 | 原始页码、表头、公式和注释 | OCR 后逐项核对影响模型的数值、负号、上下标和限定词 |

预测任务先确定独立实体和验证方案再拟合标准化、特征筛选或降维。
关联分析先定义估计对象和统计单位；重复测点不能自动增加独立样本量。
成分总量约束会影响相关性解释。是否使用原值、比值或对数比变换取决于
问题与零值机制；不得把某一种变换当作所有成分题的固定答案。

形成最小记录：输入位置 → 实际变换/排除原因 → 输出位置 → 核对结果。
候选集合也要注明定义：有成交、有报价、可供货、被允许决策不必是同一
集合。预测/补货题应按题意分别构建、连接并报告差集，不能用一张历史
报价表悄悄替换题目规定的可售集合。时间信息及事件检查另见
[temporal-validation.md](temporal-validation.md)。
当变换改变原始量时保留映射，不用论文中的处理表覆盖题目原附件。
参数-only 题不要求创建空的清洗脚本，符号推导也不要求伪造数据集。

来源与适用条件见 [玻璃案例](cases/glass-2022c.md)、
[定日镜案例](cases/solar-2023a.md)、[生产案例](cases/production-2024b.md)。
以上表格包含这些案例检查的推广，也包含尚需跨题验证的保守工程实践。
