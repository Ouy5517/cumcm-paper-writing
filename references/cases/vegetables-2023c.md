# 2023 C：销量预测、定价与补货接口

适用：历史交易流、未知未来成本、易损品补货以及预测驱动定价。以下为两篇归档作品的条件性经验，未经陌生题全面验证，不认证算法、收益或奖项。页码均为 PDF 物理页（与可见页一致）。

**来源锁定。** [CUMCM-Archive](https://github.com/yushugulao/CUMCM-Archive/tree/ef5fa17360e7ea37547320849eac1469403cda97)，commit `ef5fa17360e7ea37547320849eac1469403cda97`。题面和附件可读；论文标签“优秀/获奖”来自归档索引，未独立核奖。NOTICE 保留原权利人权利，未发现统一许可证；不随 skill 分发原论文或附件。

**互补作品。** A=`C228.pdf`《基于价格弹性的蔬菜类商品自动定价与补货决策》（70页）：LSTM 预测后作价格弹性修正，PSO/NSGA-II 决策，正文代表方案加全量附录。B=`C235.pdf`《基于历史数据的蔬菜类商品定价与补货决策模型》（73页）：Prophet 分解与价格外生项、局部模拟退火，较细地讨论价格有效域、计算预算及新增数据。两者均不能据拟合或启发式搜索宣称未来真实收益/全局最优。

1. **先固定交易粒度与需求代理。** 触发：流水转日销量或销量被称为需求。操作：以日期、单品编码关联附件，区分负数退货、无成交、未供货和缺货；为补零、删异常及需求代理注明条件。验收：销量与金额对账，排除清单可追溯，需求范围没有随利润筛选悄悄缩小。失败：保留观测销售量，补采库存/失销信息后再推断潜在需求。来源：题p1；A p5–7、24；B p4–5、27。独立核得878,503条流水、461条退货且均负数量；不能把B排除折扣及低利润成交的规则当普遍需求定义。

2. **补货时点决定可用信息。** 触发：用售价、进价或单品集合预测并决策。操作：记录预测起点与字段可获得时刻；日历可预知，未来进价须预测/情景化，候选售价是决策变量；可供、有成交、可选集合分别留ID。验收：输入不越过信息截止点；集合差异有解释。失败：缺未来协变量时预测它或缩小主张，不填未来实值。来源：题p1凌晨进货说明；A p24、B p27；独立核6月24–30日正销售49种、批发价61种，12种仅有批发价。该差异不自动判定哪个集合才是唯一正确答案。

3. **训练拟合与未来验证分开。** 触发：报告R²、平滑后相关或七天预测成绩。操作：按时间外窗口重建训练与评估，变换只在训练期拟合，逐预测步对比同信息集基线；未来无标签只给预测。验收：成绩能由截止点、标签和预测清单复算。失败：旧分数降为训练拟合/未核验，重做回测。来源：A p19表5–6；附录O p51代码29–31行全量训练，p52第55–68行在trainX上预测计分；B p18–23报告拟合并作邻域中值处理。仅核可见路径，未证明历史所有运行相同；平滑后的高相关不能代替原始时间外误差。

4. **价格改变时，预测—决策链必须一起更新。** 触发：优化器调用需求模型或逐日滚动。操作：明确基准销量/价格、弹性或回归项、成本与情景版本；改变候选价格后实际更新销量与利润，并传播预测成本误差。预测生成的后续销量标为模拟状态，不能混入“新观测”而宣称再验证。验收：接口单位、日期、来源状态一致；比较固定历史与递推情景。失败：冻结受影响排名，修复接口再算。来源：A p20–21式(7)–(14)；B p24将当日预测成交追加作下一日历史。该递推可作为情景方案，不能创造真实标签。

5. **销量加权价格与损耗现金账分别核对。** 触发：品类均价、损耗率进入收益。操作：保存分子分母；分别记采购、原价/折价售出、报废、退货和期末库存，采购成本按实际采购量计；未覆盖费用时不称完整净利润。验收：质量守恒、单位一致，售价×对应销量回到收入；损耗数据能支持所用分流定义。失败：损耗机制不明则给明确假设或情景，不把全部损耗当折价售出。来源：A p5、18、21；B p17、24、33；题p1说附件4为近期盘点损耗。窗口食用菌销量加权价5.2948元/kg，流水单价算术均值11.2256，分母不可互换。

6. **过滤候选与输出约束共同验收。** 触发：先按销量/需求评分筛选，再求补货组合。操作：保留原可选集、每轮排除与搜索范围，检查导出订单的种数、最小量及各品类需求覆盖；罚函数不替代硬约束检查。验收：逐条给剩余量和违规对象。失败：恢复必要候选或报告不可行，不能以漂亮收益掩盖缺口。来源：题p1问题3；A p24–27筛选48→45→40，B p27–32从61种设约束；A p21要求销量≤进货量，但p23表9花菜24.14>23.37。此为展示表与所写约束的0.77kg差异，不等于复现求解器失败。

7. **正向写作：正文讲代表决策，附录交完整清单。** 触发：七天×品类或几十单品结果过长。操作：正文用一张代表表串起预测、价格、补货和解释，完整结果另列并明确入口。验收：日期×对象覆盖题目，摘要数值能回到表及约束检查。失败：补齐真实缺项后重核，不能只把标题写成“七天”。来源：A p23表9与p38–39附录H覆盖七日；B p25–26表5–8标题七天，实际仅列7月1–6日。组织方式可迁移，A表值正确性仍须独立核验。

8. **正向写作：把方法选择、适用域和新增数据接起来。** 触发：选复杂模型、压缩计算或写问题4。操作：围绕需解释/预测的量说明模型选择；写清有效价格区间与运行预算；把新数据逐项连到待解除假设、方程或约束。验收：读者能看出新增库存、保鲜/报废或竞争价格信息具体改变什么。失败：退回较简模型或保留限制，不以算法简介和数据愿望清单充数。来源：B p17、25、32–34；A p28–30。仅吸收论证组织，不认可其中未经本轮核验的动态规划公式或普遍算法优劣断言。
