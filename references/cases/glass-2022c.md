# 2022 C：玻璃成分、分组与证据一致性

适用：多采样点、成分比例、风化分组、分类及逆向估计任务。下列规则是条件性建议，不是对参赛解答或获奖原因的认证。

证据分层：**运行核验**指独立 Python 数据审计及分类器逻辑译写；**静态证据**指题面、PDF视觉检查和代码读取；**候选建议**指尚未对本题重新训练验证的方法。未运行原 MATLAB/SPSSPRO 流程，未认证论文公式与全部结果。下面页码均为 `最终论文.pdf` 的 PDF 页码，与可见页码相同。

1. **先确定观测单位。** 触发：一个对象有多个检测部位。行动：保留“文物编号—采样点”两级键；若目标是推广到新文物，按文物分组验证。验收：连接无遗漏，报告点数与文物数，训练和测试文物集合不交叉。失败：修复主键或缩小推断范围，不以随机拆分行替代。来源：题面第2页；独立核得58件文物、69点，其中11件各有2点。分组检验是候选方案，并不证明不同文物完全独立。[技术依据：分组交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-iterators-for-grouped-data)

2. **筛选先于归一化，按问题保留样本。** 触发：题面给出有效总量区间或某字段缺失。行动：先在原百分比尺度求已检测成分之和，保存筛选理由，再作变换；颜色缺失不自动删除成分分析样本。验收：本题15、17号的79.47%、71.89%被标记，保留67点；颜色缺失19、40、48、58号仅影响所需字段的分析。失败：追溯筛选口径，不靠归一到100%使无效记录变有效。来源：题面第1页、论文第5–6页；运行核验。85%–105%仅是本题输入规则。

3. **分开文物与采样点的风化属性。** 触发：风化文物上含未风化点。行动：保存两个字段，依题面解释点位标签，按类型和点位风化状态汇总。验收：本题10个“未风化点”不被误归风化；有效高钾未风化/风化为12/6点，铅钡为23/26点，均附对象数。失败：回查采样点名称与定义，不凭整件标签覆盖局部状态。来源：题面第2页说明(1)–(4)、论文第7页；运行核验四组SiO₂均值与表2–3四位小数相符。

4. **成分约束与未检出要先说明。** 触发：特征为组成同一整体的比例。行动：区分未检出、记录零和缺失，说明百分数/比例及闭合处理；按目标比较可解释基线与合适的成分方法。验收：本题324个空白、4个显式零被保留为不同状态；若用CLR，先有可辩护的正值输入处理及敏感性检查。失败：保留描述性结论和方法待定状态，不盲填零取对数。来源：题面第1页、README第6行；[CLR官方文档](https://scikit.bio/docs/dev/generated/skbio.stats.composition.clr.html)。CLR仅是候选，不是唯一正确方法。

5. **把风化前重建视为有假设的逆向估计。** 触发：利用风化/未风化横截面差异推断历史成分。行动：定义所估量、配对依据、可识别假设与误差；区分空间未风化点参照和真实历史测量。验收：输出非负性、总量与不确定性检查，保留无法识别的参数。失败：给条件性范围，停止宣称已证明风化反应机制。来源：论文第12–13页、`Question1.m:24–48`；32行存储重建值总和为87.4961%–107.6208%（运行核验）。输入有效区间不能直接充当预测验收规则；原重建公式未认证。

6. **验证集必须能由清单重建。** 触发：论文声称留出验证或100%准确率。行动：保存样本ID、分组、种子及预处理/特征选择范围，独立重算分母和预测。验收：数据、脚本与论文描述指向同一拆分。失败：把该成绩标为未核验并重建验证。来源：论文第15–17页写8:2随机拆分；`Quesion2.m:2–11`却取编码表前55行。存储验证表11个文物中9个也出现在该训练切片（运行核验）；实际历史GUI拆分未知，不能据此断言当年执行过程。

7. **敏感性检查要确实作用于所称变量。** 触发：扰动后分类不变，或两个模型预测一致。行动：按成分名映射列号，记录扰动与闭合/补偿规则，核对模型读取路径；稳定率、模型一致率与有真值的准确率分别报告。验收：输入变化符合方案，真实标签的来源可核查。失败：重做扰动或降级结论。来源：论文第23页称扰动SiO₂，第24页将不变称100%准确率；`Quesion3.m:8–12`实际改第11成分P₂O₅，而`classify.m`不读取它。独立译写8点、9级扰动均不变，只验证了可见代码路径。

8. **数据、表格、图和分支共用可追踪来源。** 触发：人工处理表、硬编码图值或流程图与程序并存。行动：按主键比较变换前后值，给例外修改理由，由结果生成图表，并检查关键分支。验收：原始附件→处理表→论文数值可追溯。失败：冻结相关结论，修复并重算受影响输出。来源：附件表单2 `H62/H63` 的Fe₂O₃为0.42/0.23，`铅钡风化.xlsx!M21/M22`为2.19/3.19；对应均值0.5846与0.7665，论文第7页采用后者（运行核验）。另见`drawp10.py:17`、`Quesion2.m:44–65`硬编码值；不能把现成图片视为已复现实验。
