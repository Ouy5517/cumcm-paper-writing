# Reader contract

Organize each CUMCM manuscript so a reader can follow this sequence:

1. **What is answered:** state the subproblem, requested output, and decision
   target without replacing the original question.
2. **Why this model:** explain why the formulation, assumptions, and inputs
   fit that subproblem, including meaningful alternatives or limits.
3. **What result:** present the calculated, estimated, optimized, or simulated
   result with its scope, units, and evidence source.
4. **Why it is credible:** place derivation, checks, validation, sensitivity,
   and uncertainty next to the result they support.
5. **Where it applies:** state the population, scenario, assumptions, and
   identifiable boundary; distinguish observation from extrapolation.

This is a reader-facing argument sequence, not a required section-title or
page-layout rule. Retain natural table flow and apply emphasis selectively.
