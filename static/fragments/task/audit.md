# Audit mode

Audit content, evidence, notation, citations, anonymity, reproducibility, and
submission format. Report exact findings with severity and repairs; do not
claim that a paper passes a rendered-layout check without inspecting the
rendered artifact.

Load consistency-sweep.md only for full-paper or multi-round consistency checks
or suspected abstract/body/conclusion disagreement. Load layout-diagnosis.md
only for observed layout/typesetting, table-wall, sparse-page, stranded-heading,
float, or overflow issues; inspect rendered pages before diagnosing a remedy.
