# Preflight mode

Load references/preflight.md. Check the delivery forms requested or required
by verified selected-year rules. If both physical and electronic packages apply,
check them separately; inspect a support archive only when applicable. Mark
irrelevant forms NOT APPLICABLE, then check cross-file consistency.
Use ready_with_author_checks only when the checked artifacts are otherwise
complete and remaining author actions are identified. Missing required results,
unverified rule coverage or failed checks block submission readiness. Human
review remains pending until actually confirmed by the team.
