# Restructure mode

Reverse-outline the supplied paper, locate duplicated or unsupported claims,
and propose a section/paragraph map. Preserve correct material. Apply targeted
edits only after identifying whether a change is local or structural.

For full-paper restructuring, load consistency-sweep.md only when a multi-round
consistency review or abstract/body/conclusion disagreement is involved. Load
main-text-discipline.md only when result placement, compression, or repeated
tables require an evidence-allocation decision.
