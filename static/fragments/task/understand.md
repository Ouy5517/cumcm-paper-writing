# Understand the problem

Read the original problem, all numbered questions and attachments before model
selection. Record the year/problem ID from the supplied material, source pages,
requested quantities or decisions, output precision/format, hard constraints
and evaluation criteria. Distinguish what is given, what must be estimated and
what can be chosen. Do not infer an objective from the topic alone.

Build the problem coverage matrix with dependencies between outputs. Check that
every verb in the question has a corresponding deliverable, including explain,
compare, estimate, design and validate. Extract constants into a parameter record
with units and source locations; mark ambiguous wording with its consequence.

Return a concise problem interpretation and the first independently solvable
subquestion. Ask only about ambiguity that materially changes the answer, while
continuing independent work. A provisional model idea may have an unknown result.
