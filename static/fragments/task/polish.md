# Polish mode

For a single sentence or short passage, inspect its supplied meaning, evidence
boundary and terminology and return a local edit. Do not require the problem,
year, complete model, section map or a new ledger unless the edit depends on it.
Do not strengthen vague praise into a quantified result without evidence.

For larger revisions diagnose task coverage, section purpose, evidence placement, terminology and
notation, and claim boundaries before sentence-level editing. Preserve correct
content and revise only the affected passage unless the correction changes the
argument structure. Return polished Chinese text plus compact revision notes.
