# Draft-paper mode

Build the full argument before writing full prose. Route and load these section
values in argument order: `problem-analysis`, `assumptions-notation`,
`model-formulation`, `solution-results`, `validation-sensitivity`,
`model-evaluation`, `conclusion`, `references`, `appendix`, then `abstract`.
The abstract prose is drafted after results and validation stabilize. Keep the
body concise, and reserve implementation details, file inventory, and complete
source code for the appendix where appropriate.
