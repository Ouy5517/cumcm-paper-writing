## Purpose

State the concise problem–method–key result–validation–boundary chain and answer each subproblem.

## Required inputs

Use the stabilized problem-coverage matrix, results, validation findings, and evidence ledger.

## Structure

Draft last: problem context, method, subproblem answers, validation signal, and applicability boundary.

## Evidence boundary

Use no invented numbers. Do not include citations or reference markers in the abstract; keep source mapping in the main text and reference list.

## Common failures

Writing it before results stabilize, omitting a subproblem, or claiming unsupported performance.
