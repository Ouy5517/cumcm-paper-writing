## Purpose

Document verified code policy, support files, and readable excerpts while retaining the complete project.

## Required inputs

Use the verified appendix policy, code inventory, build record, support-file inventory, and tested source.

## Structure

State the policy, list support files, map readable excerpts to runnable source, and identify dependencies.

## Evidence boundary

Keep complete runnable code outside excerpts and mark unresolved policy compliance as unchecked.

## Common failures

Unreadable listings, treating excerpts as standalone code, or omitting required support files.
