# Rendered delivery

Render DOCX/PDF only after the source is internally checked. For Word/DOCX,
inspect the Word rendering; for PDF, inspect page order, abstract overflow,
margins, footer numbering, figures, equations, fonts, references, appendix,
and anonymity. Inspect each chart at final page scale: title/caption, labels,
units, denominator, legend, line style, and observation-versus-fit distinction
must remain readable.
Treat page, typography, and anonymity requirements as binding only when verified
against the selected year's official CUMCM notice and supplied template.
